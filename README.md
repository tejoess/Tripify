# Tripify 💸

This is a simple **Flask web app** to manage trip expenses and split bills between friends.  
It helps track who paid what, calculate how much each person owes, and generate reports with charts 📊.

## 🚀 Features
- Create multiple trips
- Add people and their expenses
- View who owes whom (settlement report)
- Track spending history
- Visual reports: category-wise & person-wise spending

## 🛠️ Built With
- Python 🐍
- Flask 🌶️
- HTML + CSS + JS
- Chart.js (for reports)
